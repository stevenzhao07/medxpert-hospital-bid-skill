# 中国医院进院全流程 · 从挂网到上量

> 中国医疗器械进院的标准流程，每一步都有坑。

---

## 完整流程（8步）

```
1. 医保收费编码 → 2. 省级挂网 → 3. 找代理商 → 4. 医院立项
     → 5. 招标/议价 → 6. 科主任/设备科/伦理 → 7. 进院证 → 8. 上量
```

---

## 步骤1：医保收费编码

**是什么**：产品在医院收费目录里有没有对应项目，没有就没法收费。

**怎么做**：
- 查国家医保局《医疗服务项目分类与代码》
- 查当地医保局的医疗服务价格目录
- 如果没有，要申请新增收费项目
- 耗材走耗材编码（国家医保耗材分类代码）

**周期**：3-12个月（新增收费项目很慢）
**坑**：没有收费编码，进了院也没法用。

---

## 步骤2：省级挂网（阳光采购平台）

**是什么**：各省卫健委的医药采购平台，产品挂网后才有资格进医院。

**怎么做**：
- 在目标省份的药品/医疗器械采购平台注册
- 提交资质文件（注册证、生产许可、授权书等）
- 等待审核
- 审核通过后公示挂网价格

**周期**：1-3个月/省
**坑**：每个省要单独挂，全国31个省要一个个来；挂网价格会被压。

---

## 步骤3：找代理商/经销商

**是什么**：厂家一般不直接做医院，要找当地经销商。

**怎么做**：
- 按省/区域找经销商
- 签授权书（注意授权层级：一级代理→二级代理）
- 明确价格、返利、区域保护

**坑**：
- 授权链条太长，利润被层层瓜分
- 代理商手里有多家竞品，不一定主推你的
- 窜货问题

---

## 步骤4：医院立项

**是什么**：医院决定要不要引进这个产品。

**怎么做**：
- 找临床科室主任（产品用在哪个科室）
- 科主任认可后向设备科提交立项申请
- 准备产品资料、临床文献、价格
- 部分医院要走医院学术委员会/药事会

**周期**：3-6个月
**坑**：没有科主任点头，后面都走不下去。

---

## 步骤5：招标/议价

**两种模式**：

| 模式 | 适用 | 说明 |
|------|------|------|
| 公开招标 | 大额设备/批量耗材 | 医院发招标文件，多家投标 |
| 谈判议价 | 小额/独家产品 | 一对一议价 |

**招标参数的重要性**：
- 厂家可以影响招标参数（通过科室主任提需求）
- 参数写得太宽泛：被小品牌低价抢
- 参数写得太具体（锁定独家）：有合规风险，被举报围标

---

## 步骤6：医院内部审批

一般要过几道关：
1. **临床科室**：科主任同意用
2. **设备科/采购科**：审核资质、价格
3. **医务科**：审核临床使用规范
4. **伦理委员会**：部分高风险产品/新技术要过
5. **院长办公会/院务会**：大额设备要上会
6. **纪委/审计**：合规审查

**周期**：1-6个月（看医院效率）

---

## 步骤7：签合同/进院证

- 中标/议价通过后签采购合同
- 拿到正式的"进院"资格
- 完成入库流程

---

## 步骤8：上量（销售启动）

进院证只是开始，真正上量要：
- 科室培训（医生/护士会用）
- 跟台服务（手术类产品要有人跟台）
- 学术推广（会议、文献、案例）
- 持续维护客情

---

## 进院必备资质清单

| 资质 | 厂家 | 进口 |
|------|------|------|
| 医疗器械注册证 | ✅ | ✅ |
| 生产许可证 | ✅ | 境外生产许可 |
| 营业执照 | ✅ | ✅ |
| 经营许可证（代理商） | 二/三类需要 | 同左 |
| 授权书（厂家→代理商） | ✅ | ✅ |
| 检验报告 | ✅ | ✅ |
| 产品技术要求 | ✅ | ✅ |
| 说明书标签 | ✅ | ✅ |
| 报价单 | ✅ | ✅ |
| 上市后不良事件监测说明 | ✅ | ✅ |

## 常见坑

1. **先做产品再想收费编码**——拿证了才发现没法收费，白做
2. **招标参数没设计好**——被低价中标
3. **只搞定设备科**——临床科室不用，库存积压
4. **授权链条乱**——一家医院好几家代理商，互相杀价
5. **挂网价格全国不一致**——价格联动，全国被压
6. **没做学术推广**——产品进了院，医生不会用，量起不来
